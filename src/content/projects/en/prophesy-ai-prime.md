## Overview

An AI-powered market intelligence solution that supports information discovery and knowledge
retrieval through LLM-based workflows — a retrieval-augmented assistant backed by automated
news collection and a document question-answering API.

## My responsibilities

- Designed and implemented the RAG pipeline.
- Developed the FastAPI backend.
- Integrated AnythingLLM and ChromaDB.
- Implemented document ingestion and retrieval workflows.
- Integrated OpenAI and Anthropic Claude models.
- Developed automated news collection workflows using n8n.

## Technical implementation

- Data collection and ingestion through automated n8n workflows.
- Document processing and embedding generation.
- Vector storage using ChromaDB.
- Retrieval-Augmented Generation over the embedded corpus.
- Multi-provider LLM integration (OpenAI and Anthropic Claude).
- API-based application integration through FastAPI.

## Results

- An end-to-end RAG application in place: collection, ingestion, retrieval, and
  question-answering through an API.
- Multi-provider LLM integration with automated content pipelines.

## What I learned

- Designing end-to-end RAG applications.
- Integrating different LLM providers behind one application surface.
- Knowledge retrieval architecture.
- Workflow automation and backend integration.
