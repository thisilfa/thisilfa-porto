## Gambaran

Solusi intelijen pasar berbasis AI yang mendukung penemuan informasi dan pengambilan
pengetahuan melalui alur kerja LLM — asisten retrieval-augmented yang ditopang pengumpulan
berita otomatis dan API tanya-jawab dokumen.

## Tanggung jawab saya

- Merancang dan mengimplementasikan pipeline RAG.
- Mengembangkan backend FastAPI.
- Mengintegrasikan AnythingLLM dan ChromaDB.
- Mengimplementasikan alur kerja ingest dan retrieval dokumen.
- Mengintegrasikan model OpenAI dan Anthropic Claude.
- Mengembangkan alur kerja pengumpulan berita otomatis menggunakan n8n.

## Implementasi teknis

- Pengumpulan dan ingest data melalui alur kerja n8n otomatis.
- Pemrosesan dokumen dan pembuatan embedding.
- Penyimpanan vektor menggunakan ChromaDB.
- Retrieval-Augmented Generation di atas korpus embedding.
- Integrasi LLM multi-provider (OpenAI dan Anthropic Claude).
- Integrasi aplikasi berbasis API melalui FastAPI.

## Hasil

- Aplikasi RAG menyeluruh yang berjalan: pengumpulan, ingest, retrieval, dan tanya-jawab
  melalui API.
- Integrasi LLM multi-provider dengan pipeline konten otomatis.

## Yang saya pelajari

- Merancang aplikasi RAG menyeluruh.
- Mengintegrasikan berbagai provider LLM di balik satu permukaan aplikasi.
- Arsitektur retrieval pengetahuan.
- Otomasi alur kerja dan integrasi backend.
